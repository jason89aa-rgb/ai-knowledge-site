표를 넘기기 전에 JSON 한 건 검수하기

게시일 2026년 11월 24일

‘주문 번호, 수량, 메모’를 AI에 정리시킨 뒤 자동화 도구로 보내려고 합니다. 화면에서는 숫자 2와 문자열 "2"가 비슷하지만 덧셈을 수행하는 다음 단계에는 차이가 생깁니다.

입력 계약을 종이에 써 보기

연습용 주문 번호는 007, 수량은 2, 메모는 없습니다. 주문 번호는 앞의 0을 보존하는 문자열, 수량은 양의 정수, 메모는 문자열 또는 null로 정합니다. 이 규칙을 지키는 예시는 아래 한 건입니다.

{
  "order_id": "007",
  "quantity": 2,
  "note": null
}

세 종류의 실패 분리하기

닫는 중괄호가 빠지면 JSON 자체를 읽을 수 없습니다. quantity가 "2"이면 읽기는 가능하지만 형식 검사에 실패합니다. quantity가 0이면 정수여도 업무 규칙에 걸립니다. 세 경우 모두 원본 주문 번호를 남기고 보류하면 잘못된 수량이 뒤 단계까지 넘어가는 일을 막을 수 있습니다. 수업의 완료 기준은 이 세 실패를 서로 다른 이유로 설명하는 것입니다.
