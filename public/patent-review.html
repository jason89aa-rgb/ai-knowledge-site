미국 심사철 자동 다운로드

Chrome 확장 기능을 설치하면 EZ Patents의 심사문서 ZIP이 리포트에 자동으로 들어옵니다.

확장 기능 다운로드 (.zip)
Chrome 설치 방법
  1. 위 버튼으로 ZIP을 내려받고 이 컴퓨터에 계속 보관할 폴더에 압축을 풉니다.
  2. 데스크톱 Chrome 148 이상에서 주소창에 chrome://extensions를 입력하고 오른쪽 위 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르고 manifest.json이 들어 있는 폴더를 선택합니다.
  4. 목록에 AI-ALL 미국 심사철 ZIP이 표시되면 운영 리포트 페이지를 다시 엽니다. 미국 특허를 찾아 심사문서 다운로드를 누르세요.

미리보기는 운영과 별도의 EPO 인증 설정을 사용합니다. 운영 리포트 열기
